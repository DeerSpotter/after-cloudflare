# Flareless v0.1.0 Operational Config Pass

This pass makes the local demo more user defined and persistent while keeping honest local demo boundaries.

## Added

- Visual topology editor controls for adding nodes and links.
- Topology JSON editor remains available for advanced edits.
- Topology snapshots with restore support.
- Saved named custom scenarios.
- Custom scenario reload and delete support.
- Health check simulation settings per provider.
- Provider registry derived from topology provider nodes.
- Release zip now includes docs and an empty runtime state folder.
- Tests for operational config persistence.

## New runtime files

Runtime files are created under `tools/local-demo/state/`:

```text
local-ui-state.json
topology-config.json
topology-snapshots.json
custom-scenarios.json
health-settings.json
provider-registry.json
```

## New local API endpoints

```text
GET  /scenarios/custom
POST /scenarios/custom
POST /scenarios/custom/run
POST /scenarios/custom/{id}/delete
GET  /health/settings
POST /health/settings
GET  /providers/registry
POST /providers/registry
GET  /topology/snapshots
POST /topology/snapshots
POST /topology/snapshots/{id}/restore
```

## Still not production behavior

This is still a local simulation. It does not perform real CDN control plane changes, real distributed health checks, real peer chunk transfer, or detached manifest signature verification.
