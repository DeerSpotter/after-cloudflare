# Flareless v0.1.0 UI Phase 1

This phase focuses on the release quality command center shell before deeper backend capabilities are added.

## Added

- Componentized embedded UI files under `tools/local-demo/ui/`.
- Real MapLibre command map inside the Python GUI.
- Navigable application shell with separate views.
- Provider page with normalized CDN health table.
- Evidence page for generated `x-flareless-*` headers and route trace JSON.
- Animated route overlay layer.
- Provider cards anchored to map coordinates using MapLibre markers.
- Approval inbox cards with approve and reject actions.
- Policy builder controls with add/remove condition, YAML/JSON toggle, test action, and disabled save.
- Micro CDN peer view with rejected peer handling and trust boundary display.
- Toast notifications.
- `tools/local-demo/requirements.txt` for pywebview.

## Preserved

- Startup remains paused.
- No scenario runs automatically.
- No polling starts automatically.
- Live policy mutation remains disabled.

## Still future work

- Real persisted policy backend.
- Real peer chunk transfer.
- Detached manifest signatures.
- Production multi-CDN integration.
- Installer packaging.
