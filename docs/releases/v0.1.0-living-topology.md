# Flareless v0.1.0 Living Topology

This update turns the topology page into a living topology surface instead of a fixed diagram.

## Added

- Persistent topology config endpoint: `GET /topology/config`.
- Save topology config endpoint: `POST /topology/config`.
- Local topology config file: `tools/local-demo/state/topology-config.json`.
- Editable topology JSON panel in the Topology page.
- User defined nodes, links, positions, radii, labels, and kinds.
- Provider IDs from custom scenarios are automatically represented as live topology nodes.
- Scenario Builder provider options now follow the current topology config.
- Topology node status is derived from route trace, provider health, active provider, and Micro CDN fallback state.
- Active path, standby path, failed path, and Micro CDN states are rendered dynamically.
- Node details drawer works for topology nodes defined by the user.

## Behavior

The topology is now driven by two layers:

1. **Topology config** defines what exists: nodes, labels, kinds, positions, and links.
2. **Runtime state** defines what is happening: route trace, providers, active provider, failures, and Micro CDN trust state.

This means you can rename providers, add another CDN, move nodes, create additional links, then run a scenario that uses those provider IDs and the page updates as a live graph.
