# Flareless v0.1.0 Operational UI

This pass makes the local UI feel operational instead of purely visual.

## Added

- Node details drawer.
  - Click MapLibre provider cards.
  - Click MapLibre nodes.
  - Click topology nodes.
  - Shows status, latency, last result, active/standby/failed role, route attempts, and Micro CDN trust boundaries.

- Scenario Builder.
  - Build a custom failover chain in the UI.
  - Example: CloudFront timeout -> Fastly blocked -> Cloudflare success.
  - Export custom scenario JSON or YAML.
  - Run custom scenario against the local API.

- Local JSON persistence.
  - Saves history and events to `tools/local-demo/state/local-ui-state.json`.
  - Reloads saved history/events on UI startup.

- Release packaging helpers.
  - `tools/local-demo/install_requirements.bat`
  - `tools/local-demo/build_release_zip.bat`
  - ZIP includes launchers, UI files, scenarios, screenshots, docs, and Python runtime files.

- Topology upgrade.
  - Clickable topology nodes.
  - Active path highlight.
  - Edge labels for latency/result/trust role.
  - Improved active/standby/failed legend.

## Still future work
