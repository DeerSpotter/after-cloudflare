# Flareless v0.1.0 UI Phase 2

Phase 2 expands the local command center from a visual shell into a decision and state inspection UI.

## Added

- Route Replay page with slider based step reconstruction.
- Incident Timeline page generated from route attempts and recommendations.
- Metrics Dashboard page with request, latency, error, and provider distribution visuals.
- Event Bus Viewer for UI and route state transitions.
- Network Topology page with local SVG topology.
- Historical Runs page backed by front end state.
- AI style explanation panel in Settings.
- Extended front end state object with history, events, metrics, replay, and current page data.

## Preserved

- Startup remains paused.
- No scenario runs automatically.
- No polling starts automatically.
- Policy save remains disabled until backend persistence exists.
- Live policy mutation remains disabled.

## Still future work

- Persistent historical run storage.
- Real metrics ingestion.
- Real event bus backend.
- Editable scenario builder.
- Real force directed topology engine.
- Production grade explanation agent.
