# Flareless v0.1.0 UI Phase 3: Cockpit Topology

This phase improves the operator feel of the embedded local command center.

## Added

- Draggable topology nodes inside the topology canvas.
- Dragged node positions update the local topology config in memory.
- Save Topology persists the moved positions.
- Topology nodes dynamically shrink as node count grows.
- Topology header shows node count, active provider, failure count, and current average radius.
- Metrics page now renders as a cockpit style dashboard.
- Cockpit metrics include route attitude, primary gauges, annunciators, provider matrix, event tape, traffic distribution, and readiness bar.

## Operator behavior

Topology movement is local until the operator presses `Save Topology`. This keeps dragging safe and reversible while experimenting.
