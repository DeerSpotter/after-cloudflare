# Flareless v0.1.0 UI Phase 2.5

Phase 2.5 turns the topology screen from a static diagram into a live state visualization.

## Added

- Live topology colors based on the current route trace.
- Active nodes shown in green with glow.
- Standby nodes greyed out with reduced opacity.
- Failed nodes shown in red with failure marker.
- Micro CDN standby and active states shown separately in blue.
- Animated traffic packets along active and failed links.
- Topology legend for active, standby, and failed states.
- Topology summary showing active provider and failed node count.

## Preserved

- Startup remains paused.
- No scenario runs automatically.
- No polling starts automatically.
- Topology is still driven by local scenario data only.

## Still future work

- Real force directed topology engine.
- Draggable nodes.
- Side drawer on node click.
- Real throughput and latency labels per edge.
- Persistent topology snapshots.
