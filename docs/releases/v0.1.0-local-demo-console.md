# Flareless v0.1.0 Local Demo Console

This is the recommended first release target for Flareless.

## Primary artifact

```text
python tools/local-demo/run_demo.py
```

The release experience is the local Python command center, not the static browser demo.

## Included in this release build

```text
OSIRIS inspired 2D vector map assets
Global Smart Traffic & Failover Map
provider health normalization
route attempt chain
route trace JSON
x-flareless-* evidence headers
visual route policy builder
YAML and JSON policy export
agent recommendation inbox
operator approve or reject workflow
lifecycle audit log
Micro CDN trust dashboard
release tour playback
```

## Restored browser demo boundary

The `demo/` folder remains the original lightweight mobile browser simulation. It is not the command center UI.

## Honest scope

Implemented:

```text
local route simulation
local provider failover scenarios
local recommendation lifecycle
local approval and rejection audit events
local hash verified cache trust model display
```

Not implemented:

```text
real peer chunk transfer
distributed health checks
detached manifest signatures
production control plane
external CDN provider API integration
```

## Validation target

```text
python tools/local-demo/run_tests.py
```

The CI local demo job must pass on Python 3.12.
