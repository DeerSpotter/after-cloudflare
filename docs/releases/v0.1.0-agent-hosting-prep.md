# Flareless v0.1.0 Agent and Hosting Prep

This update starts preparing the local demo to become a real operator tool.

## Added

- Agent Ops naming for the former Approvals view.
- Settings controls for selecting a free local agent or a paid API compatible agent.
- Paid API marker fields for provider type, model, and API key configured state.
- Raw API keys are not persisted by the local demo. The demo stores only a masked preview and configured flag.
- Hosted location registry in Settings.
- Hosted location fields for host type, domain, host/account URL, web root path, detected file, apply mode, and notes.
- Setup assistant recommendation generator for host onboarding.
- Safe apply modes: instructions only, patch only, and future credentialed apply disabled.
- GUI close behavior setting: close local server or keep it running until Ctrl+C.
- Local app settings persisted in `tools/local-demo/state/app-settings.json`.

## Product safety rule

Automatic changes to a hosted account must remain disabled until all are true:

1. Credentials are configured.
2. Target file is detected.
3. Backup is created.
4. Diff is shown.
5. Operator explicitly approves Apply.
6. Action is written to audit history.
